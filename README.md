# carpooling-app
# 🚗 Carpooling Web App

A PHP & MySQL-based carpooling platform where users can **register**, **offer rides**, **book rides**, and **manage travel plans**. Designed for college students and commuters to share rides efficiently.

---

## 📁 Project Overview

This is a server-side web application built with **PHP (procedural)** and **MySQL**, styled with **CSS**. All logic runs on the backend, and there is **no JavaScript frontend framework involved**.

---

## 🛠 Tech Stack

| Category        | Technology      |
|----------------|-----------------|
| Backend        | PHP             |
| Database       | MySQL           |
| Styling        | CSS             |
| Hosting        | InfinityFree    |
| Web Server     | Apache          |

---

## 📌 Features

✔ User Registration & Login  
✔ Post a Ride  
✔ Search & Book Rides  
✔ Canceling bookings  
✔ Payment simulation (`pay.php`, `payment_start.php`, `payment_success.php`)  
✔ User Dashboard (`dashboard.php` & `dashboard2.php`)  
✔ Vehicle registration (`add_vehicle.php`)  
✔ Basic grievance system (`grievance.php`)  
✔ Sessions & Logout support  
✔ Database storage using `carpool.sql`
